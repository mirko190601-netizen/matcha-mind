# Matcha Mind

Gehirnjogging im Teegarten – eine iOS-/iPadOS-App mit 14 Denkspielen in drei Stufen (Sencha, Oolong, Matcha), Garten-Fortschritt und Teepause-Ritual.

Dieses Repo enthält nur den App-Code.

Projekt per [XcodeGen](https://github.com/yonaskolb/XcodeGen) aus `project.yml` erzeugt – keine `.xcodeproj` im Repo.
